Analisis de salud

Autor: Yamel Calderon

este dataset incluye informacion sobre la salud de diferentes paises del mundo, algunos son:
esperanza de vida
mortalidad infantil
gastos de salud
etc

ejecutar el proyecto 
Clonar el repositorio:
git clone
Entrar a la carpeta:
cd tu-repositorio
Instalar dependencias (si aplica):
pip install pandas matplotlib
Abrir el notebook:
jupyter notebook
Ejecutar todas las celdas:
Ir a Kernel → Restart & Run All


Los países con mayor nivel de ingresos tienen, en promedio, una mayor esperanza de vida.
Existe una relación inversa entre la mortalidad infantil y el nivel de vacunación.
Las regiones con menor inversión en salud presentan peores indicadores sanitarios.
